# Logistics Enquiry & Company Website

A modern, responsive web application for a logistics company. Built using React, TailwindCSS (v4), and Vite, featuring a premium design with smooth layouts, interactive pricing/enquiry calculators, tracking interfaces, and contact forms.

## Features

- **Dynamic Enquiry & Calculator**: Interactive tool for users to estimate shipping/logistics costs based on parameters like weight, volume, destination, and shipping speed.
- **Shipment Tracking**: User-friendly tracking dashboard mockups.
- **Services Catalog**: Clear display of core logistics operations, air/sea/land freight, warehousing, and customs clearance.
- **Modern UI**: Styled with TailwindCSS v4 and Framer Motion for smooth micro-animations.

## Technology Stack

- **Frontend**: React (v18)
- **Styling**: TailwindCSS (v4)
- **Icons**: Lucide React & React Icons
- **Bundler**: Vite
- **Routing**: Wouter
- **State/Form Management**: React Query & React Hook Form with Zod validation

## Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed (version 18 or above recommended).

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/aarebkhan02/LogisticsEnquiry.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Logistics-Company-Website
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

### Running Locally

To start the development server:

```bash
npm run dev
```

The application will be accessible at `http://localhost:5173`.

### Building for Production

To build the project for production:

```bash
npm run build
```

This will generate static assets inside the `dist/` directory, optimized and ready for deployment.
