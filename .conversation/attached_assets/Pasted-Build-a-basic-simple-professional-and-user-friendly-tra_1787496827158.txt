Build a **basic, simple, professional and user-friendly transportation and logistics company website prototype** using **React.js**.

## Project Structure

Create the project inside a folder named:

`frontend`

Use:

* React.js
* Vite
* CSS
* React Router if needed
* JavaScript/JSX

**Do NOT create a backend.**
**Do NOT create a database.**
Use only dummy/static data for this prototype.

The goal is to create a **conceptual website framework** that can be shown to the client for approval before full development.

---

# 1. Overall Design

Create a clean, modern and professional logistics/business website.

The design should feel similar to a professional international transportation, shipping and logistics company.

### Design principles

* Simple
* Professional
* Trustworthy
* Corporate
* User-friendly
* Fully responsive
* Fast and lightweight
* Not overly animated
* Avoid excessive gradients
* Avoid flashy effects
* Focus on content and functionality

Use a professional color palette such as:

* White
* Dark navy / deep blue
* Light blue
* Small yellow/gold accents

Keep plenty of white space.

Use clean typography such as Inter, Poppins or a similar modern font.

---

# 18. Important

This is a **client presentation prototype**, not the final production website.

Therefore:

* Keep it simple
* Make it visually professional
* Prioritize usability
* Avoid unnecessary animations
* Use realistic dummy content
* Use high-quality logistics images
* Make all buttons and navigation work on the frontend
* Make the inquiry form functional on the frontend
* Make WhatsApp and chat UI work as a prototype
* Do not build a backend
* Do not add payment gateways
* Do not add real authentication
* Do not add real shipment tracking

The final result should look like a **real professional transportation and logistics company website**, while remaining simple enough to demonstrate the proposed project structure to the client.

After completing the implementation, make sure the application runs correctly with:

`npm run dev`
